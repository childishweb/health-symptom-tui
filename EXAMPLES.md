# 📝 Usage Examples

Real-world scenarios showing how to use the Health Symptom Tracker effectively.

## Example 1: Daily Migraine Tracking

**Scenario**: You get frequent migraines and need to track patterns for your neurologist.

### Morning Entry
```
Press 1 (Quick Entry)
↓ Select "Headache"
Tab → Type: 8
Tab → Type: "Woke up with severe migraine, light sensitivity"
Tab → Type: "Right side of head, behind eye"
Tab → Type: "Started during sleep, ongoing 3+ hours"
Tab → Type: "Didn't sleep well, stressed yesterday"
Tab → Type: "Sumatriptan 50mg at 7am"
Tab → Skip notes
Ctrl+S
```

### Follow-up Entry (After Medication)
```
Press 1
↓ "Headache"
Tab → 4 (severity decreased)
Tab → "Migraine improved after medication, mild headache remains"
Tab → "Right temple"
Tab → "30 minutes post-medication"
Tab → "Same as before"
Tab → "Sumatriptan helped"
Ctrl+S
```

### Weekly Export for Doctor
```
Press 4 (Export)
Click "Export to .txt"
→ Email the file to your doctor before appointment
```

## Tips from These Examples

### Be Consistent
- Track at the same times daily when possible
- Use similar language for recurring symptoms
- Rate severity consistently

### Be Specific
- Include exact times and durations
- Note what you ate, did, or took
- Weather, stress levels, sleep quality

### Use Notes Field Liberally
- Questions for your doctor
- Patterns you notice
- Things you want to try
- What helped or didn't help

### Review Regularly
- Weekly: Look for short-term patterns
- Monthly: Review trends
- Before appointments: Export and review

### Export Strategically
- **For doctors**: Use .txt format (clean, printable)
- **For yourself**: Use .org format (structured, searchable)
- **Before appointments**: Export recent entries

### Search to Find Patterns
Use the search feature to answer questions like:
- "How often do I get headaches?"
- "Does weather affect my pain?"
- "Are my symptoms improving?"
- "What medications work best?"

## Keyboard Speed Tips

### Fastest Entry Method
For quick logging, only fill required fields:
```
1 → Select symptom → Tab → Number → Tab → Brief description → Ctrl+S
```
**Time: ~8 seconds**

### Template Approach
For recurring symptoms, keep notes of your usual entry:
- Copy/paste descriptions
- Use same severity scale
- Note deviations only

### Tab Through Optionals
Don't click - just Tab through fields you want to skip!

---

**Remember**: The more detailed your tracking, the more useful it is for identifying patterns and discussing with healthcare providers. But don't let perfection stop you - a quick entry is better than no entry!
